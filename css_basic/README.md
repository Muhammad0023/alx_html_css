# 🎨 CSS Basics Project

A clean, beginner-friendly webpage that demonstrates core **CSS styling techniques**.  
The code shows how to:

- Apply styles inline, internally, and through an external stylesheet  
- Use **classes** and **selectors** to target elements effectively  
- Handle **CSS specificity** so the right styles win  
- Work with the **box model**—content, padding, border, and margin

## 💻 Tech
- HTML5  
- CSS3
